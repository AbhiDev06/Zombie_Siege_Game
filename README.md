# 🧟 Zombie Siege — Survival Shooter Game

Zombie Siege is a browser-based survival shooting game built using HTML, CSS, and JavaScript. Defend your base against endless waves of zombies, choose your weapons wisely, and survive as long as possible!

## 🎮 Features

- 🧟 Multiple zombie types with different health, speed, and damage.
- 🔫 Three weapons: Pistol, Rifle, and Shotgun.
- 🎯 Mouse aiming and shooting, with touch support.
- 🔄 Weapon reloading system.
- ❤️ Base health tracking and health recovery.
- 🏆 Score tracking and progressively challenging waves.
- ✨ Shooting effects, hit effects, and screen shake.
- 📱 Responsive canvas designed to fit different screen sizes.
- 💾 Best score saved locally in the browser.

## 🕹️ How to Play

1. Start the game.
2. Aim at incoming zombies using your mouse or touch screen.
3. Click or touch and drag to shoot.
4. Switch weapons using the buttons or keyboard shortcuts.
5. Reload your weapon when ammunition runs low.
6. Prevent zombies from reaching your base!

## ⌨️ Controls

| Action | Control |
|---|---|
| Aim and shoot | Mouse click / touch and drag |
| Select Pistol | `1` |
| Select Rifle | `2` |
| Select Shotgun | `3` |
| Reload | `R` |
